## Problem

The wizard and CLI output are currently in German only. Users who prefer English or other languages cannot use the tool in their preferred language. Internationalization (i18n) would make the tool accessible to a broader audience.

## Solution

Implement i18n support using Go's standard i18n packages:

- Use `golang.org/x/text/language` for language detection
- Store translation files in `locales/` directory (JSON or YAML format)
- Support locale detection from: CLI flag → environment variable → system locale → fallback to English
- Default languages: English (en), German (de)

**Files to modify:**
- `internal/i18n/` - New package for translations
- `cmd/oshell-config/main.go` - Add --locale flag
- `internal/wizard/wizard.go` - Use i18n for prompts

**Translation structure:**
```
locales/
├── en.yaml   # English (fallback)
├── de.yaml   # German
└── (additional languages)
```
