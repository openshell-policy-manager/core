## Areas Discussed

### Reset Scope — Target directories

| Option | Description | Selected |
|--------|-------------|----------|
| Presets-Cache + defaults.yaml | Nur ~/.config/ospm/presets/ löschen und defaults.yaml zurücksetzen. Templates bleiben. | |
| Presets + Templates, behalte defaults.yaml | Presets und Templates neu herunterladen, aber defaults.yaml des Users behalten. | ✓ |
| Ganzes ~/.config/ospm/ löschen | Alles in ~/.config/ospm/ entfernen. User startet komplett neu. | |
| Presets + Templates + defaults + blueprint | Auch ~/.oshell-config/ mit zurücksetzen. Alles auf Auslieferungszustand. | |

**User's choice:** Presets + Templates, behalte defaults.yaml
**Notes:** "Presets und Templates sollen neu heruntergeladen werden, defaults.yaml bleibt erhalten"

---

### Delivery State

| Option | Description | Selected |
|--------|-------------|----------|
| Neu herunterladen | Presets + Templates fresh vom GitHub Repo holen. Default-Zustand = aktueller Stand auf GitHub. | ✓ |
| Eingebaut | Presets + Templates sind im Binary eingebettet (go:embed). Reset = eingebettete Version wiederherstellen. | |
| Leer / kein Preset | Reset = löschen ohne neu herunterladen. User muss explizit "ospm preset update" aufrufen. | |

**User's choice:** Neu herunterladen

---

### Confirmation & Safety

| Option | Description | Selected |
|--------|-------------|----------|
| Immer bestätigen | "ospm reset" zeigt eine Liste was gelöscht wird und fragt yes/no. Sicher. | ✓ |
| Nur bestätigen ohne --yes | Standard: fragt. Mit --yes: überspringt die Bestätigung. | |
| Dry-run zuerst | Standard: zeigt nur was passieren würde. Mit --execute: wirklich löschen. | |

**User's choice:** Immer bestätigen
**Notes:** "Immer bestätigen — kein automatisches Löschen ohne Nachfrage"

---

### --all Flag

| Option | Description | Selected |
|--------|-------------|----------|
| Ja, --all für vollständigen Reset | "ospm reset" = Presets+Templates. "ospm reset --all" = zusätzlich .oshell-config/ löschen. | ✓ |
| Nein, nur Presets+Templates | Scope bleibt auf Presets und Templates beschränkt. .oshell-config/ ist nicht Teil dieses Resets. | |

**User's choice:** Ja, --all für vollständigen Reset

### Command Name

| Option | Description | Selected |
|--------|-------------|----------|
| ospm reset | "ospm reset" als eigener Top-Level-Befehl. --all Flag für vollständigen Reset. | |
| ospm preset reset | Reset als Sub-Command unter "ospm preset". Passt zur "ospm preset update" Logik. | ✓ |
| ospm reset presets | "ospm reset presets" als separates Subcommand. Flexibel für künftige Reset-Typen. | |

**User's choice:** ospm preset reset

### Post-reset Behavior

| Option | Description | Selected |
|--------|-------------|----------|
| Sofort neu herunterladen | Nach dem Löschen automatisch "ospm preset update" aufrufen. User hat direkt wieder funktionierende Presets. | ✓ |
| Manueller Update nötig | Löschen und fertig. User muss explizit "ospm preset update" aufrufen. | |

**User's choice:** Sofort neu herunterladen

### No-presets Edge Case

| Option | Description | Selected |
