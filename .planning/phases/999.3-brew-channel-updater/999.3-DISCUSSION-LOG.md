## User's Provided Architecture

The user provided a comprehensive architecture document covering:

### Repository Structure
| Repository | Purpose | Visibility |
|------------|---------|------------|
| `openshell-policy-manager/ospm` | Go source + GoReleaser config | public/private |
| `openshell-policy-manager/homebrew-ospm` | Homebrew tap with formula | **must be public** |

### Release Flow
```
git tag -a v0.1.0-alpha.1 -m "Alpha release"
git push origin v0.1.0-alpha.1
# ↓ GitHub Actions → GoReleaser → Binaries → GitHub Release → Formula-Update
```

### Key Decisions Captured
- Two-repo architecture (source + separate public tap)
- GoReleaser for cross-platform builds and formula generation
- PAT with `repo` scope required as `GORELEASER_TOKEN` for cross-repo write
- macOS builds preferred for Homebrew compatibility
- Alpha/stable taps are separate
