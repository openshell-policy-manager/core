# Phase 999.3: Brew Channel Updater - Context

**Gathered:** 2026-04-12
**Status:** Ready for planning

<domain>
## Phase Boundary

Automated Homebrew formula/channel updates for OSPM releases. Keeps the Homebrew tap in sync with GitHub releases using GoReleaser. Users can install via `brew install openshell-policy-manager/ospm/ospm`.

</domain>

<decisions>
## Implementation Decisions

### Repository structure
- **D-01:** Two-repository architecture:
  - `openshell-policy-manager/ospm` — Go source code + GoReleaser config (public or private)
  - `openshell-policy-manager/homebrew-ospm` — Homebrew tap with formula (must be **public**)
- **D-02:** Tap follows Homebrew schema: `brew install {user}/{tap}/{formula}` → `openshell-policy-manager/ospm/ospm`

### Build and release automation
- **D-03:** GoReleaser handles cross-platform builds (darwin/amd64, darwin/arm64, linux/amd64, linux/arm64)
- **D-04:** GoReleaser generates SHA256 checksums and formula file from template
- **D-05:** GitHub Actions workflow triggers on git tag push
- **D-06:** Workflow runs on `macos-latest` (Homebrew prefers macOS builds)

### Release workflow
- **D-07:** Developer workflow: `git tag -a v0.1.0-alpha.1 -m "Alpha release" && git push origin v0.1.0-alpha.1`
- **D-08:** Tag format for alpha: `v*.*.*-alpha.*` (semantic versioning with prerelease suffix)
- **D-09:** GoReleaser uses `prerelease: auto` to detect prerelease tags and mark GitHub Release as Pre-Release

### Cross-repo authentication
- **D-10:** Standard `GITHUB_TOKEN` only has permissions to the triggering repo
- **D-11:** Separate PAT with `repo` scope required as `GORELEASER_TOKEN` secret
- **D-12:** `GORELEASER_TOKEN` enables GoReleaser to push formula to `homebrew-ospm` repo

### Alpha vs stable
- **D-13:** Alpha releases use separate tap: `openshell-policy-manager/homebrew-ospm-alpha`
- **D-14:** Stable releases update `homebrew-ospm` tap
- **D-15:** Prerelease suffix in tag determines which tap receives the update

### Manual one-time setup (not automatable)
- **D-16:** Create GitHub org `openshell-policy-manager`
- **D-17:** Generate PAT with `repo` scope
- **D-18:** Add PAT as `GORELEASER_TOKEN` secret in `ospm` repo
- **D-19:** Create `homebrew-ospm` repo explicitly as **public** (Homebrew requirement)

### Installation commands
- **D-20:** Stable: `brew install openshell-policy-manager/ospm/ospm`
- **D-21:** Alpha: `brew install openshell-policy-manager/ospm-alpha/ospm`

</decisions>

<specifics>
## Specific Ideas

- "Two repos required — source code repo + separate public tap repo"
- "PAT is mandatory because GITHUB_TOKEN can't write to a different repo"
- "macOS builds preferred by Homebrew, even for Linux-supporting binaries"
- "goreleaser generates Formula from template and commits to tap repo post-build"
- "Formula push happens automatically after binaries are uploaded to GitHub Release"

</specifics>
