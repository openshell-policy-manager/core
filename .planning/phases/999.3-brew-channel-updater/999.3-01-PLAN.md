<task type="auto">
  <name>Task 2: Create GitHub Actions release workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
Create `.github/workflows/release.yml` with:

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

permissions:
  contents: write

jobs:
  goreleaser:
    runs-on: macos-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
      
      - name: Setup Go
        uses: actions/setup-go@v5
        with:
          go-version: '1.22'
      
      - name: Run GoReleaser
        uses: goreleaser/goreleaser-action@v6
        with:
          version: latest
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          GORELEASER_TOKEN: ${{ secrets.GORELEASER_TOKEN }}
```

Key points per D-05 and D-06:
- Triggers on git tag push (`on: push: tags: 'v*'`)
- Runs on `macos-latest` (Homebrew prefers macOS builds)
- Uses both GITHUB_TOKEN and GORELEASER_TOKEN (GITHUB_TOKEN can't write to other repos - D-10)
- GORELEASER_TOKEN is the PAT with repo scope (D-11, D-12)
</action>
  <verify>
<automated>test -f .github/workflows/release.yml && grep "on:" .github/workflows/release.yml | grep -q "tags"</automated>
  </verify>
  <done>GitHub Actions workflow created, triggers on tag push, runs on macos-latest</done>
</task>
