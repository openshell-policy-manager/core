# Phase 999.2: Openshell Gateway Warning - Context

**Gathered:** 2026-04-07
**Status:** Ready for planning

<domain>
## Phase Boundary

Add warning functionality to ospm when OpenShell gateway is not available. The warning appears during ospm init and other operations that depend on OpenShell being accessible.

</domain>

<decisions>
## Implementation Decisions

### Detection method
- **D-01:** Use CLI check via `openshell version` command — check exit code and JSON output to determine availability

### Warning behavior
- **D-02:** Non-blocking warning — show yellow warning message but continue command execution
- **D-03:** Warning output includes gateway URL and suggestion to check OpenShell installation

### Caching
- **D-04:** Cache gateway status for 5 minutes to avoid repeated `openshell version` calls

### the agent's Discretion
- Exact warning message text and formatting
- Which commands trigger the check (all commands or only specific ones)

</decisions>
