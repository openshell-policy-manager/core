# Requirements: OpenShell Configuration

**Defined:** 2026-04-05
**Core Value:** Secure development environment: OpenCode can perform all required operations, but only with the minimal necessary rights and access.

## v1 Requirements

### Installation

- [x] **INST-01**: OpenCode can be installed via brew
- [x] **INST-02**: OpenCode can be installed via direct download
- [x] **INST-03**: Installation guide is documented and easy to follow

### Base Configuration

- [x] **BASE-01**: CLI command exists for configuration application
- [x] **BASE-02**: Configuration uses secure defaults (no permissive rights)
- [x] **BASE-03**: Auto-update is disabled by default
- [x] **BASE-04**: External directory access is restricted
- [x] **BASE-05**: Destructive commands (rm -rf) require confirmation

### OpenShell Integration

- [x] **OSHELL-01**: Select existing sandboxes from openshell sandbox list
- [x] **OSHELL-02**: Query GitLab URL in interactive dialog
- [x] **OSHELL-03**: Securely store GitLab Deploy Token (600 permissions)
- [x] **OSHELL-04**: Generate OpenShell Policy YAML (valid per schema)
- [x] **OSHELL-05**: Apply policy to sandbox with openshell policy set
- [x] **OSHELL-06**: Mask token on input (show only first4...last4)
- [x] **OSHELL-07**: Remember GitLab URL (do not ask again)

### GitLab Integration

- [x] **GITL-01**: GitLab OAuth tokens can be configured
- [x] **GITL-02**: Read access to GitLab repositories works
- [x] **GITL-03**: Write access (push) to GitLab repositories works
- [x] **GITL-04**: GitLab credentials are stored correctly (without override)

### Network Security

- [x] **NETW-01**: Network access to GitLab is allowed
- [x] **NETW-02**: Free internet access for web research is enabled
- [x] **NETW-03**: Only data from explicitly approved sources is downloaded

### Sandbox & Skills

- [ ] **SAND-01**: OpenCode sandbox with all skills is configurable
- [ ] **SAND-02**: MCP servers approved in OpenCode can be used
- [ ] **SAND-03**: Websearch/Webfetch skills are usable
- [ ] **SAND-04**: Codesearch skill is usable
- [ ] **SAND-05**: File operations skills are usable
- [ ] **SAND-06**: Git operations (status, diff, commit) are usable

### CLI Interface

- [x] **CLI-01**: A single command applies the configuration
- [x] **CLI-02**: Command can gradually unlock permissions (phase by phase)
- [x] **CLI-03**: Command shows current configuration status
- [x] **CLI-04**: Dry-run mode for testing without changes

## v2 Requirements

### Advanced Security

- **SEC-01**: Audit trail for all configuration changes
- **SEC-02**: Rollback function for previous configurations
- **SEC-03**: Time-limited credentials with auto-refresh

### Network Advanced

- **NETW-10**: Selective network access (only GitLab and known dev services)
- **NETW-11**: Network whitelist instead of free access

## Out of Scope

| Feature | Reason |
|---------|--------|
| OpenShell installation | Configuration only, no installation |
| Full dev environment (npm/node, git cli) | Out of scope — OpenCode only |
| Admin features on GitLab | Not required for development |
| Docker container isolation | macOS native sandbox-exec sufficient |
